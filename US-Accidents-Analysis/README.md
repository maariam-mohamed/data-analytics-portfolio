# US Accidents Data Analysis & Tableau Dashboard

## Project Overview

Analyzed the US Accidents dataset to explore accident patterns, severity, locations, and trends.

## Tools

- Python
- Pandas
- Tableau

## Work Done

- Cleaned and prepared the dataset using Python and Pandas
- Performed data analysis to identify important patterns
- Created an interactive Tableau dashboard
- Developed visualizations to present accident trends and key insights

## Dashboard

Interactive Tableau dashboard showing key accident metrics, trends, and geographic patterns.
